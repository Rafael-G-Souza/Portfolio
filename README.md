# 🚀 Meu Portfólio Pessoal

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para centralizar minhas informações, exibir meus principais projetos e facilitar o contato com recrutadores e parceiros.

Você pode visualizar o projeto online através do link abaixo:
> **[Link para o Portfólio no Ar](https://rafael-g-souza.github.io/Portfolio/)** 

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, focando em performance e design responsivo:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização avançada, incluindo:
    - **CSS Grid & Flexbox:** Para um layout moderno e responsivo.
    - **Animações & Transições:** Efeitos de hover e interatividade.
    - **Design Dark Mode:** Estética moderna e confortável.
- **JavaScript (Vanilla):** Lógica de interatividade, como:
    - **Custom Cursor:** Um cursor personalizado que segue o movimento do mouse.
    - **Botão "Voltar ao Topo":** Melhora a navegação em páginas longas.
    - **Efeitos de Scroll:** Controle de visibilidade de elementos.

---

## ✨ Funcionalidades Principais

- **Seção Home:** Apresentação impactante com foco em Full Stack.
- **Sobre Mim:** Detalhes sobre minha trajetória e habilidades técnicas.
- **Galeria de Projetos:** Exibição de cards com links diretos para os repositórios.
- **Contato:** Botões estilizados para WhatsApp, E-mail, LinkedIn e GitHub.
- **Responsividade:** Totalmente adaptado para dispositivos móveis, tablets e desktops.

## 🚀 Como rodar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Rafael-G-Souza/Portfolio.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd Portfolio
   ```
3. Abra o arquivo `index.html` no seu navegador preferido.
