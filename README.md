🚀 Meu Portfólio Pessoal - Rafael Souza
Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar as minhas competências, projetos e experiências como Desenvolvedor FullStack Jr..

📋 Sobre o Projeto
O objetivo deste projeto é servir como uma vitrine digital onde partilho a minha paixão por tecnologia e inovação. A interface foi desenhada para ser funcional, acessível e proporcionar uma ótima experiência ao utilizador, refletindo o meu foco em construir soluções digitais de qualidade.

🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

HTML5: Estruturação de conteúdo.

CSS3: Estilização, incluindo o uso de Flexbox, CSS Grid para a grelha de projetos e comportamentos de animação (efeito de cursor personalizado).

JavaScript: Implementação de interatividade, como o seguimento do mouse pelo cursor personalizado.

📂 Estrutura de Pastas
index.html: Arquivo principal com a estrutura da página.

styles.css: Estilização completa do site, incluindo media queries para design responsivo.

img/: Pasta contendo os recursos visuais e capturas de ecrã dos projetos.
